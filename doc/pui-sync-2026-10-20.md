## Native implementation

Both boxes observe the nearest physical parent's content size, skipping virtual
views. Unknown sizes choose the second direction; equality selects the first.
The existing size subscription handles redraw and cleanup. The native container
and child identities remain unchanged across direction switches. wx updates its
axis expansion priorities; Qt updates divider orientation and spacer policies.
LVGL restores parent-imposed child sizes before applying the next layout so a
label that filled a column returns to its intrinsic width in a row.

The shared cookbook uses only CPPUI declarations. Its adaptive example retains
one text field in `HVBox(600)`, uses `VHBox(500)` for height-dependent labels,
and changes a label's padding/color/font through wide modifiers at 600 pixels.
Following PUI's later update, the gallery now keeps its menu beside the result
at narrow widths and starts at 1024×768 without maximizing. Native test helpers
remain in `tests/cookbook/`.

Wide modifiers observe the nearest non-virtual parent's content width.
Unknown sizes do not match; the minimum is inclusive. Calls apply in declaration
order, regardless of threshold order, and omitted values leave prior settings
unchanged. A resize rebuilds declarations from their base values, restoring
them below the threshold while retaining native identity. CPPUI uses its typed
named/positional modifiers and borrowed `const char*` font families. There is no
breakpoint table or string-key dispatch.

LVGL now implements `Window().size(w,h)` for Application-owned SDL2/X11 hosts,
so the cookbook's window declaration remains shared. Both the native host and
LVGL resolution change; unchanged declarations preserve a user's resize.
Borrowed displays retain their owner's resolution.

Resizing also exposed an existing Qt Scroll edge case: an unspecified native
`sizeHint()` dimension is -1. Minimum dimensions now clamp that hint to zero,
with a warning-capture regression. Negative scroll offsets and end anchoring
retain their existing meaning.

virtual ancestors, retained native boxes/editors, draft text and cursor position,
direction-dependent child sizing, stable measurement suppression and removal.
Wide modifier checks cover unknown/exact widths, declaration order, omitted/zero
values, borrowed text, virtual ancestors, native identity and restoration.
Cookbook checks resize the horizontal gallery and exercise both forms bound to
the shared input state. HeavyCanvas interaction checks
allocate enough window space for its existing minimum 320×360 chart size.

ASan/UBSan/leak checks. LVGL adaptive and desktop-host checks exercise the SDL2
and X11 variants, including resize preservation and borrowed-display ownership.

`-j "$(nproc)"`. The complete core/Qt/wx/examples suite passed 73 tests; SDL2 and
X11 each passed 26, totaling 125. One wx adaptive resize check initially failed
during a concurrent build, then passed five isolated repeats and the complete
suite rerun without background compilation; no production change was made for
that transient result.

All four normal cookbooks were launched and their live native windows checked.
Qt/SDL2/X11 show 1024×768 client windows; wx uses its existing decorated-window
size semantics for the same declaration. Source hashes matched before and after
the builds. No benchmark results are retained.
