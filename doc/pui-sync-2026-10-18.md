## Native implementation and performance choices

CPPUI already searches reconciliation vectors from an index, whereas PUI's
optimization removes a temporary Python list slice. Copying that change would
add no C++ benefit. No additional painter style-cache guards are introduced;
the previous [native measurements](canvas-performance.md) still apply.

Refs use lifetime tokens instead of retaining raw retired C++ declarations.
Commands posted by workers are applied only by the UI thread. Qt/wx use native
posting; LVGL drains a mutex-protected queue on its refresh timer. This timer is
created only for referenced LVGL nodes. Window commands are desktop-only;
LVGL refs expose selection. Existing wx/LVGL Tabs optional State models remain
separate older gaps. This sync does not silently claim full backend parity.

Options stay strings, use strict percent/UTF-8 decoding, preserve literal `+`,
and skip malformed entries with warnings. Their function-local map initializes
on first access, the header-only C++ counterpart to Python import initialization.

Drop payloads own their values. Files and directories refer to original native
paths; acceptance performs no filesystem operation. Qt scroll-area viewports
are included. wx sizer-only layouts and LVGL host file-drop bridging remain
unsupported by the current wrappers; outgoing drags/model reordering are separate.

Landlock requires ABI 3+ and a single thread when applied. It uses native
syscalls, with no AI or Python runtime dependency. See [policy semantics](landlock.md).
