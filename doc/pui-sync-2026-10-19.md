## Native behavior

Initially hidden containers defer child creation. Mounted hidden subtrees retain
native controls and their drafts, discard fresh child declarations, and defer
nested view updates until shown. Removing a hidden subtree still releases it.
Callbacks and timers on retained nodes continue. Unsupported visibility targets
such as Window and virtual nodes retain CPPUI's existing behavior; apply
`.visible()` to their physical content.

`size().get()` returns a read-only `Optional<Size>` and tracks the reading view.
The binding is empty until layout supplies a measurement. Observers follow
retained native objects, coalesce callbacks, suppress equal measurements and
stop when their node is removed. Saved bindings keep their last measured value.
`VisibilityBounds` supplies optional minimum/maximum width/height constraints on
the nearest physical parent's content area. Minima are inclusive, maxima
exclusive, and unknown dimensions hide constrained branches.

Qt uses content rectangles minus layout margins, including a main window's
central content. wx uses allocated sizer sizes or window client sizes. LVGL
observes content extents excluding padding/borders. The LVGL implementation is a
native counterpart to the committed common PUI contract; PUI has no LVGL backend.
All native observation code stays in backend headers. The Adaptive cookbook
uses only public shared CPPUI declarations and the committed PUI recipe's
600-pixel threshold and shared text state.

## C++ choices

Hidden-child freezing avoids native reconciliation work in C++ too, while
preserving the same lazy creation and state semantics. Thaw refreshes walk live
nodes after reconciliation rather than retaining raw pointers that a synchronous
child redraw might delete. Ordinary redraws skip that walk when no thaw is pending.

Size observation is allocated only when used. Previous declarations supply the
same reactive state before `content()` evaluates its breakpoints, with distinct
anonymous siblings matched in reconciliation order, including insertion/removal
of unrelated siblings, and keyed reorder support. Native callbacks hold
weak observation state and never depend on a retired declaration pointer.
Read-only geometry uses the existing view dependency protocol; generic writable
State notification behavior is unchanged.

PUI's State constructor repair is Python-specific: CPPUI already initializes the
stored value directly without invoking mutation notifications. Python wrapper
validity workarounds are replaced with native Qt/wx weak handles and LVGL delete
events. There is no new painter optimization in this range. No benchmark output
or results are retained.
